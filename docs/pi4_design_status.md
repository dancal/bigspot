# Raspberry Pi 4 조립 설계 상태

이 커밋은 진행 중인 설계를 보존한다. 제작 승인이나 실물 동작 완료를 뜻하지 않는다. 기존 `selected_design.json`의 기준 실험과 새 `pi4_design.json`의 실험을 구분한다.

## 포함된 구성

| 구성 | 현재 상태 |
|---|---|
| Raspberry Pi 4 Model B | 공식 PCB 외형·장착 구멍 반영, RAM 미확인 |
| RobStride RS00 ×4, RS02 ×8 | 외형·제조사 장착 패턴 반영, 실물 치수·나사 깊이 미측정 |
| Waveshare ESP32-S3-CAN-2CH | 외형 배치, 2개 CAN 버스 계획, 실물 제어 펌웨어 없음 |
| RealSense D435i | 외형·전방 브래킷 배치, 실제 센서 연결 미시험 |
| 몸체 IMU | BNO085 SPI 후보, 기존 센서 모델 미확인 |
| 초음파·발 접촉 센서 | 장착 공간 예약, 기존 센서 호환·교정 미확인 |
| 배터리 | 12S1P P42A 공급업체 조립 팩 후보, 43.2V/4.2Ah, 팩 미선정 |
| DC/DC | Mean Well RSD-30L-5, 입력 18–72V / 출력 5V 6A 후보 |
| BMS·모터 차단·프리차지·퓨즈·회생 보호·워치독 | 필요한 공간·요구 조건만 예약, 부품 SKU와 회로 미확정 |

Waveshare 보드의 전원 단자에는 12S 배터리를 직접 연결하지 않는다. Pi 4 및 MCU는 검증된 5V 전원 경로를 사용해야 한다. Pi USB 전력 예산은 DC/DC의 6A 정격과 별개이며, D435i·MCU를 연결한 실제 측정이 필요하다. 기존 7.4V 배터리와 PCA9685는 새 CAN 모터 전원·제어 구성으로 사용할 수 없다.

## 확인한 내용

- CAD 입체 유효성: 170개 BRep 유효.
- 구매 부품 예약 상자끼리의 정적 겹침: 발견하지 않음. 검사 대상은 일부 전자 부품 외형이며 모든 부품이 아니다.
- CAD 기반 질량·관성 적용: 추정 9.213722kg. 부품 질량과 배선 여유는 실측 전 추정값이다.
- MuJoCo 시험: 일어서기 10초, 보행 15초, 무게 +15%·마찰 0.55 보행 15초 통과. 모터 연속 토크 한도는 정격의 60%로 가정했다.
- 상세 결과: `design/pi4/validation.json`, `validation/pi4_dynamics.json`.

## 해결할 내용

1. Pi 4 트레이·배터리 트레이의 높이와 지지대 연결을 다시 검토해야 한다. 현재 일부 장착 받침은 프레임까지의 지지·체결 구조가 끝나지 않았다.
2. 몸체·배터리·브래킷을 포함한 전체 정적 간섭과 관절 운동 중의 실제 CAD 간섭을 검사해야 한다. 물리 모델의 충돌 없음으로 대신할 수 없다.
3. 카메라의 물리 모델은 아래 12°를 보지만, 현재 STEP 카메라 외형에는 이 회전이 반영되지 않았다. 브래킷과 함께 수정해야 한다.
4. Fusion 스크립트의 STEP 가져오기·13개 그룹·12개 회전 관절·네이티브 F3D 저장을 실제 Fusion에서 검증해야 한다. 실행 보고서나 F3D 파일은 아직 없다.
5. 모터 출력부 지지·베어링 하중·프레임 강도·나사 결합·열 전달·배선 굽힘 여유를 검증해야 한다. 충격 동작은 승인하지 않았다.
6. MCU 센서 수집·CAN 출력·워치독 펌웨어, 전원 보호 회로, 실제 센서·카메라·ROS 통합을 구현하고 시험해야 한다.
7. Pi 4 변경안의 자율 이동·센서 단절 시험은 아직 실행하지 않았다. 이전 7.48kg 기준 모델의 결과를 이 변경안의 결과로 사용하지 않는다.
