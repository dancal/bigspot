# Raspberry Pi 4 R3 조립 설계 상태

R3 SPORT는 스포츠형 외형과 지지 구조를 수정한 검토용 CAD다. 추정 질량 9.833952kg, 유효 BRep 164개, 관절 그룹 13개, 회전 관절 12개를 포함한다. 제작 승인은 아직 하지 않았다.

## 수정한 구조

- 경사진 중공 상부 외장, 탈착 측면 패널, 전후 보호 커버를 추가했다. 측면은 어깨 형상에 맞춘 곡선으로 파냈으며 전자부품을 감싼다.
- 펄 그레이의 낮은 외장과 가늘어지는 앞뒤 커버, 짙은 관절 커버, 주황색 트림을 스포츠형 외형으로 정리했다. 상부 높이를 프레임 기준 56mm로 낮추고 측면 외장을 2mm로 만들었다. 상부 외장과 패널에 M3 체결 패턴, 프레임 접촉 지지부, 체결 탭 여유 노치와 카메라 지지대 여유 노치를 반영했다.
- 벌림 요크의 ±0.65rad 회전 범위에서 모서리 궤적 극값을 계산하고, 보수적인 경계에 여유를 더해 외장의 어깨 개구부를 잘랐다. 실제 외장을 수정한 것이며 간섭 검사에서 부품 쌍을 면제하지 않는다.
- 카메라 광학 표시와 2포트 초음파 형상은 시각 참고·공간 예약이다. 실제 공급업체의 렌즈·커넥터·음향부 상세와 치수 검증을 뜻하지 않는다.
- Pi 4·배터리·전자 모듈 받침을 프레임에 연결하고 USB 포트·배터리·팬·비상 정지 버튼의 여유 공간을 수정했다.
- D435i와 크래들을 실제 CAD에서도 아래 12°로 회전하고 프레임에 연결했다.
- 벌림 요크, 무릎 고정부와 하부 링크 위치를 조정해 접힌 자세의 간섭을 줄였다. 발 지지 목을 연결했다.
- 다리별 구조물을 연결된 단일 BRep으로 합쳤다. 일체형 구조의 시제품 기준이며 가공·분할·체결 방법은 추가 설계가 필요하다.
- CAD 질량·관성, 관절 제한과 시동 자세를 CPU 모델·URDF·Isaac 시작 설정에 반영했다. 무릎 2.55rad는 운용 제한이며 실물 기계식 스토퍼 검증을 뜻하지 않는다.

## 검증과 영상

`design/pi4/interference_audit.json`은 계획된 서기·일어서기·전진·옆 이동·회전 자세와 영상에서 기록한 실제 관절 자세를 대상으로 정확한 BRep 교집합을 계산한다. 계획·기록 자세 총 114개에서 기준을 넘는 겹침이 없었다. 겹침 판정 기준은 1mm³이며 자세별 결과를 모두 보존한다. 개별 부품의 연결된 입체 여부도 검사한다. 표본 검사로 연속 운동 전체를 인증할 수 없다.

외부 ControlCore → 모터 로컬 PD → MuJoCo 경로의 동작·고장 대응 11개 시험과 단위 시험 29개가 통과했다. CAD/URDF 외형의 단위·링크 좌표·질량·리소스 경로 및 영상 서버의 구간 요청도 검사한다. 장애물 회피는 정답 odometry를 사용하는 CPU 시험이다. 기존 내부 제어기 비교 시험은 3개 중 2개 통과했고 일어서기의 자기 접촉 기준은 실패했다. 두 경로의 결과를 구분한다.

`generated/motion_videos_pi4-r3/`에는 CAD 회전 영상과 일어서기, 전진, 옆 이동, 회전, 하중 증가, 장애물 회피, IMU·관절·제어기·명령·카메라 단절 영상이 있다. 모든 동작은 실제 계산한 물리 상태를 1배속으로 재생하며 몸체를 강제로 이동시키지 않는다. 렌더링 CAD는 상세 외형이고 물리 충돌 형상은 단순화했다. 모터 후면 지지의 CPU 접촉 여유는 1mm로 설정해 수치적인 접촉 침투를 줄였다. 이는 실물 간극 치수의 인증이 아니다.

모든 영상은 H.264 Baseline / yuv420p / faststart로 다시 생성했다. 하나의 플레이어에서 영상을 선택하고 HTTP 구간 요청을 지원하는 전용 서버를 사용한다. 12개 영상의 전체 프레임 디코딩과 구간 전송을 검사했고, Codex 브라우저에서 각각 선택한 뒤 재생 시간이 진행되는 것도 확인했다. 브라우저 검사는 재생 시작 확인이며 전체 길이 재생은 별도의 FFmpeg 디코딩 검사로 확인한다. 결과와 영상 SHA-256은 `validation/motion_media.json`에 있다.

## 실물 구성과 남은 검증

Raspberry Pi 4 Model B, RS00 ×4, RS02 ×8, D435i, Waveshare ESP32-S3-CAN-2CH, BNO085 후보와 12S1P P42A 공급업체 팩을 배치했다. BMS·차단·프리차지·퓨즈·회생 보호·워치독 부품은 공간 예약이며 SKU와 회로가 확정되지 않았다. Mean Well RSD-30L-5는 5V 전원 후보다. MCU 보드에 12S 배터리를 직접 연결하지 않는다. Pi USB 전력 예산은 실제 측정이 필요하다.

베어링 하중, 프레임 강도·피로, 나사 깊이·체결, 배선 굽힘, 방열과 실제 치수는 검증하지 않았다. MCU CAN 출력·독립 워치독 펌웨어 및 보호 회로 구현도 필요하다. 실물 모터 출력은 비활성 상태다.

Fusion의 STEP 가져오기·관절 생성·F3D 저장, 실제 ROS DDS와 Isaac GPU 실행은 아직 검증하지 않았다. GPU 환경 제약은 `docs/isaac_integration.md`와 `validation/current_host.json`에 기록했다. STEP는 상세 배치와 형상 검토용이며 완성된 제작 도면은 아니다.
